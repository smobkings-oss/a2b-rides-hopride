# A2B Rides - HopRide Rider App

Premium ride-hailing platform for NW Ohio and Michigan. Instant and scheduled Tesla rides with transparent pricing and driver-first values.

## Features

- **Instant Rides**: Request a ride immediately
- **Scheduled Rides**: Book for a future date/time with discount
- **Vehicle Selection**: Tesla Standard, Premium, or XL
- **Price Estimates**: Transparent fare calculation
- **Ride History**: View and manage past/upcoming rides
- **Profile**: Save personal details
- **Black/Gold Branding**: Holographic accents matching A2B identity

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Local storage for demo persistence (ready for Supabase)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

Optimized for Vercel. Connect your GitHub repo or use the Vercel CLI.
